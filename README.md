# Breakout Game
A classic arcade-style **Breakout** game built in Python using the built-in `turtle` module. Control the paddle, bounce the ball, and smash through all the bricks to rack up your highest score!

## Features
* **Responsive Paddle Controls:** Smooth horizontal movement to keep the ball in play.
* **Brick Destruction & Collision:** Bricks disappear upon impact with bounce physics.
* **Live Scoreboard:** Tracks your current score in real time during gameplay.
* **Zero External Dependencies:** Built using only Python's standard library (`turtle`).

##  How to Play
1. Run the Python script to open the game window.
2. Use the **Left (`←`)** and **Right (`→`)** arrow keys *(or `A` and `D`)* to move the paddle.
3. Bounce the ball off your paddle to break all the bricks at the top of the screen.
4. Keep the ball from falling past your paddle!

##  How to Run Locally
1. Ensure **Python 3** is installed on your machine.
2. Clone this repository:
   ```bash
   git clone https://github.com
   ```
3. Open the project folder:
   ```bash
   cd Breakout_game
   ```
4. Run the game *(replace `main.py` with your actual filename if different)*:
   ```bash
   python main.py
   ```

## 🛠️ Built With
* **Python 3**
* **Turtle Graphics (`turtle`)**
